# Security Policy

## Supported Versions

Currently, only the `master` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Security and trust are paramount for a decentralized payment protocol like LumiPay. If you discover a security vulnerability in the LumiPay smart contracts, frontend, or infrastructure, please do not report it through public GitHub issues.

Please securely report the issue by sending an email to our core team (or reaching out via private communication channels). We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.

If the vulnerability is validated, we will issue a patch and notify the community. Depending on the severity of the issue, we may offer a bug bounty reward.

**Thank you for helping keep LumiPay safe!**
